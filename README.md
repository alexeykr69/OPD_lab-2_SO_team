Командный проект по разработке игрового 2D-платформера на базе Unity с настроенной системой непрерывной интеграции и автоматического тестирования (CI/CD).

## 2. Спецификация сборки (docs/build.md)
Версия игрового движка: Unity 6000.6.4f1
Целевая платформа билда: Standalone Windows 64-bit (.exe)
Активная игровая сцена: Assets/IndieMarc/PlatformerDemo/PlatformerDemo.unity
Инфраструктура сборки (Runner): Ubuntu 24.04 LTS (Docker-контейнер unityci/editor)
Размер готового архива игры: 38.0 MB (сжатый билд StandaloneWindows64)

Установленные пакеты (Package Manager):
com.unity.modules.ui - модуль для работы с UI элементами интерфейса.
com.unity.2d.sprite - модуль для работы с 2D-спрайтами.
com.unity.2d.tilemap - инструмент для создания уровней из тайлов.

## 3. Архитектура каталогов (docs/structure.md)
Игровые ресурсы проекта организованы по следующей структуре:
Assets/IndieMarc/PlatformerDemo/ - корневая директория выбранного режима 2D Platformer.
Scenes/ - главная сцена игрового уровня.
Scripts/ - исходный код логики перемещения игрока и триггеров.
Sprites/ - графические ассеты, спрайт-листы и анимации персонажа.
ProjectSettings/ - конфигурационные файлы проекта.
EditorBuildSettings.asset - настройки сборщика (мусорный режим TopDown успешно исключен на уровне конфигурации).

## 4. Автоматизация и Контроль качества (CI/CD)
Перед каждой компиляцией проекта пайплайн в GitHub Actions принудительно запускает автоматический прогон тестов через Unity Test Framework (флаги -batchmode -runTests):
1. EditMode: Верификация синтаксиса скриптов и корректности компиляции кода C# без запуска игрового цикла.
2. PlayMode: Тестирование физического движка (Rigidbody2D), коллизий платформ и триггеров смерти при падении персонажа в бездну.

Любые изменения в коде автоматически тестируются облачным раннером. В случае падения тестов или ошибок конфигурации сборка автоматически блокируется, сигнализируя в систему баг-трекинга GitHub Issues.

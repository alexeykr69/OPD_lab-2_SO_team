# Changelog

## Изменения Джуниора:

- Перестроен уровень. Теперь он стал более интересней, сложнее и больше. Теперь игроку нужно будет потратить больше времени на прохождение из-за повышенной сложности и размеров уровня. (Для повышения интереса к уровню)
- Увеличена высота прыжка игрока. (Чтобы можно было реализовать более сложные препятствия и части уровня, которые будут проходимыми для игрока)
- Увеличен обзор камеры (Из-за специфики уровня игроку необходимо видеть происходящее на экране в большем объёме)

## Изменения Сеньора
- Изменён цвет фона камеры на тёмно-зелёный — для атмосферы ночного леса
- Изменена интенсивность света — для создания более мрачного настроения
- Изменён цвет деревьев на заднем фоне - для соответствия цвету фона камеры
- Изменён цвет спрайтов платформ на тёмный-зелёный — соответствие общей атмосфере ночного леса
- Настроено направление света — для более чёткого рассмотрения спрайтов травы
- Добавлен туман - для создания более мрачной атмосферы
- Изменено направление света - для регулировки контраста цветов
- Изменён цвет спрайтов травы - чтобы не сливались с платформами
- Изменён цвет основного персонажа - для большей схожести с человеком

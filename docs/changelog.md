# Changelog

## Изменения Сеньора
- Изменён цвет фона камеры на тёмно-зелёный — для атмосферы ночного леса
- Изменена интенсивность света — для создания более мрачного настроения
- Изменён цвет деревьев на заднем фоне - для соответствия цвету фона камеры
- Изменён цвет спрайтов платформ на тёмный-зелёный — соответствие общей атмосфере ночного леса
- Настроено направление света — для более чёткого рассмотрения спрайтов травы
- Добавлен туман - для создания более мрачной атмосферы
- Изменено направление света - для регулировки контраста цветов
- Изменён цвет спрайтов травы - чтобы не сливались с платформами
- Изменён йвет основного персонажа - для большей схожести с человеком

\# Документация сборки проекта (2D Platformer)



\## 1. Настройки сборки и доступные платформы

\* \*\*Текущая целевая платформа:\*\* Windows.

\* \*\*Архитектура сборки:\*\* Intel 64-bit.

\* \*\*Доступные платформы в редакторе:\*\* Только Windows. Все остальные платформы (macOS, Linux, Android и т.д.) заблокированы, не имеют загруженных модулей и требуют скачивания через Unity Hub.

\* \*\*Сцены в сборке:\*\* 'Assets/IndieMarc/PlatformerDemo/PlatformerDemo.unity'.



\## 2. Установленные пакеты

В проекте используются следующие пакеты для реализации 2D-платформера:

\* '2D Sprite' - для управления спрайтами персонажей и элементов окружения.

\* '12D Tilemap Editor' - для проектирования уровней из блоков (тайлов).

\* 'Input System' - для настройки управления персонажем (движение, прыжки).



\## 3. Структура папок и присутствующие ассеты

\* 'Assets/' - основная папка со всеми ресурсами игры.

&#x20; \* 'IndieMarc/' - корневой каталог ассетов платформера.

&#x20;   \* 'PlatformerDemo/' - папка со сценой уровня ('PlatformerDemo.unity').

&#x20;   \* 'Common/' - общие скрипты, звуковые эффекты и базовые материалы.

&#x20;   \* 'Enemy/' - спрайты, префабы и логика поведения противников.

&#x20;   \* 'Player/' - префаб игрока, анимации, скрипты физики движения и прыжка.

&#x20; \* 'Scenes/' - папка для хранения создаваемых игровых сцен и меню.

&#x20; \* 'Settings/' - файлы конфигурации управления (Input Actions).



\## 4. Приблизительный размер проекта

\* \*\*Размер папки Assets:\*\* 6,65 МБ (согласно свойствам каталога в проводнике).

\* \*\*Ожидаемый размер итогового билда:\*\* около 30-40 МБ после компиляции под ПК.
